## Tassula ry - Website Plan

### 1. Project Proposal
I will create a website for Tassula ry, a volunteer-run animal shelter near Seinäjoki, Finland.
The website will help animals find loving homes by introducing animals waiting for adoption and providing information about the adoption process. It will also help visitors learn more about the shelter and contact the volunteers.

### 2. Website Goal
The main goal is to make it easier for people to find animals looking for homes and contact the shelter about adoption.
Visitors should be able to browse animals, read their stories and learn how the adoption process works. The website should be simple, clear and easy to navigate.

### 3. Target Visitors
The website is intended for:
People interested in adopting cats.
People interested in adopting dogs.
People looking to adopt other animals.
Families searching for a new pet.
People who want to learn more about Tassula.
The website should be welcoming and easy to use for people with different levels of computer skills. Accessibility is also important because some visitors may use screen readers or other assistive technology.

### 4. Website Pages and Main Headings
Home - index.html
H1: Welcome to Tassula ry
Introduces the shelter, explains its purpose and welcomes visitors. It will give visitors a starting point for exploring the website.
About Us - about.html
H1: About Tassula ry
Explains the organisation, its volunteers and its mission to help animals find safe and loving homes.
Animals - listing.html
H1: Animals Looking for a Home
Introduces animals waiting for adoption. Visitors should be able to find information about the animals and see which animals are available.
Contact - contact.html
H1: Contact Tassula ry
Provides contact information and an adoption enquiry form so interested people can contact the shelter.

### 5. Similar Websites
I researched three real animal adoption websites for inspiration:
Onnentassu - https://www.onnentassu.fi/
Pirkanmaan eläinsuojeluyhdistys - https://pesu.org/
Kyproskissat ry - https://www.kyproskissat.fi/
I will use these websites as inspiration when planning the Tassula website. I will look at how they present animals, organise information and help visitors find adoption details.

### 6. Design Ideas
The website will have a simple, welcoming and easy-to-read design.
The planned colours are:
Dark spruce: #12343b
Pale mint: #eef6f4
Orange: #e8742a
The colours will help create a friendly appearance that suits an animal shelter. Text and backgrounds should have good contrast so that the information is easy to read.
Accessibility and readability are important when planning the website. Images will have alternative text, and pages will use clear headings and navigation.

### 7. Project Scope
For E1, I will create four basic HTML pages with headings, content and working navigation links. The website will be published using GitHub Pages.
The first version will focus on the basic structure and content of the website. More advanced styling and features can be developed in later stages of the project.
